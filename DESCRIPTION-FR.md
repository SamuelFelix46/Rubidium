# Nom

Rubidium

# Description courte

Une optimisation exacte et automatique du calcul de génération autour des structures. Fabric et Fabric API, sans réglage.

# Description détaillée

Rubidium évite certaines opérations lorsque la contribution vanilla d'enfouissement d'une structure est déjà connue comme exactement nulle. Il conserve la formule d'origine pour les autres cas et ne remplace pas les bruits, les graines ou les algorithmes de biomes. Minecraft 26.3 contient déjà ce raccourci : le build Rubidium correspondant n'ajoute aucun mixin.

L'installation normale conserve le rendu, les files graphiques et l'ordonnancement de génération de Minecraft. Aucun menu ni fichier de réglage n'est requis. Le mod désactive automatiquement son intégration de calcul en présence de C2ME pour éviter un chevauchement ; les combinaisons complètes de mods restent à vérifier séparément.

Cette version expérimentale est disponible pour Fabric 1.21.1, 1.21.11, 26.1, 26.2 et 26.3. La mise à jour alpha.2 fournit de nouveaux JAR pour 1.21.1 et 26.3, avec leurs sources et résultats d'essais. Le gain de génération observé est modeste et dépend du scénario. Une hausse générale des FPS et l'absence de saccades ne sont pas démontrées.

Le nom vient du rubidium, métal alcalin de numéro atomique 37. Identifiant technique : `rubidium_flow`. Projet indépendant de Rubidium pour Forge.
